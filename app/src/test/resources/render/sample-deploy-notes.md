# 发布说明

## 这次发了什么

- 修复了电量低于 15% 时通知不弹出的问题
- 升级了 `okhttp` 到 4.12.0
- **破坏性变更**：旧版配置文件里的 `legacyPort` 字段被移除

## 回归检查清单

- [x] 冷启动
- [x] 省电模式下通知
- [ ] 平板横屏布局（已知问题，下版本修）

## 升级提示

升级前请先备份。<br>如果你是从 1.6.x 直接升级，中间会多跑一次迁移脚本，<br>大概多花 3 秒。

部分用户反馈升级后图标变了：<b>这是预期的</b>，新图标更清晰。
